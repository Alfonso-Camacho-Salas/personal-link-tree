# 📇 Digital Business Card & Link Hub

A minimalist, mobile-first personal landing page designed to act as a digital extension of my physical business card. This webpage is optimized for instant loading and is primarily accessed via an NFC tag embedded in my physical card.

## ✨ Features

* **NFC Integrated:** Serves as the direct routing destination for tap-to-connect physical cards.
* **Mobile-First Design:** Optimized specifically for smartphone viewing, ensuring a seamless experience when tapped.
* **Minimalist UI:** Clean, block-based navigation inspired by modern terminal and agent interfaces.
* **Direct Contact:** Features a one-tap WhatsApp routing link utilizing `wa.me` for immediate communication.
* **Centralized Presence:** Consolidates links to my GitHub, LinkedIn, and Instagram into a single, easily navigable space.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for fast parsing and accessibility.
* **CSS3:** Custom styling focusing on a warm, minimalist color palette and responsive flexbox/grid layouts. No heavy frameworks to ensure maximum load speed.
